========================================
  NextGEN UX — How to open this site
========================================

OPTION 1 (easiest — no terminal):
1. Unzip this folder
2. Open the folder named "nextgen-ux"
3. Double-click the file:  index.html
4. It opens in your browser

OPTION 2 (with terminal — recommended):
1. Unzip this folder
2. Open Terminal
3. Type:  cd  (then drag the nextgen-ux folder into the terminal window and press Enter)
4. Type:  npx serve -l 3000
5. Open your browser and go to:  http://localhost:3000

Pages included:
- index.html   = Home
- blog.html    = All posts
- about.html   = About
- posts/       = 17 individual articles

If the page looks broken (no styles), use OPTION 2.
